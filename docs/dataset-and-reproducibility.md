# Data & reproducibility

Dataset: scikit-learn digits image dataset with per-image engineered tabular descriptors

Raw files should be downloaded locally with the project scripts, kept under `data/raw/`, and excluded from Git. Check the upstream terms, attribution and licence before use. Pin dependency versions for formal experiments, record the dataset version/checksum and random seed, separate training/validation/test data, and only report metrics after running the code.


Digits documentation: https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html
